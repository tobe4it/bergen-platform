# Bergen Platform Roadmap

This roadmap describes the planned evolution of the Bergen Platform.
Priorities may change as the project grows.

## Guiding Principles

- Infrastructure as Code
- Reproducible deployments
- Modular architecture
- Security by default
- Documentation first

## v0.5.1 – Open WebUI Improvements

Planned
- Automatic LDAP user activation
- Improve Open WebUI administration
- Refine LDAP integration
- Improve validation tasks
- Minor bug fixes

## v0.6.0 – AI Platform

Planned
- llama.cpp integration
- Model management
- Model download automation
- GPU improvements
- AI runtime enhancements

## v0.7.0 – Mail Platform

Planned
- Postfix deployment
- Dovecot deployment
- Rspamd integration
- DKIM automation
- Mail gateway role

## v0.8.0 – IBM MQ

Planned
- MQ Client deployment
- MQ administration automation
- MQ object management
- MQSC deployment
- MQ validation

## v0.9.0 – Infrastructure Services

Planned
- Observium
- Monitoring
- Backup
- Security hardening
- Logging improvements

## v1.0.0 – Bergen Platform

Goal
First stable public release.

Scope
- Complete AI platform
- Mail platform
- LDAP integration
- Monitoring
- IBM MQ automation
- Comprehensive documentation
- Stable release process
- Semantic Versioning
- GitHub releases

## Beyond v1.0

Potential future areas:
- Nextcloud
- Authentik / SSO
- Matrix
- Asterisk
- Kubernetes integration
- High Availability
- Multi-node deployments
- CI/CD pipelines
- Automated testing
- Community contributions
